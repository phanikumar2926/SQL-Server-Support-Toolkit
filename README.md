# SQL-Server-Support-Toolkit
Practical SQL Server scripts for database monitoring and troubleshooting

# About This Project
The SQL Server Support Toolkit is a collection of practical SQL scripts designed to help IT and application support engineers with database monitoring, administration, and troubleshooting.

# Project Objectives
- Check database status and health.
- Monitor database size and storage.
- Review SQL Server backup history.
- Identify active sessions and blocking processes.
- Retrieve table records for investigation.
- Troubleshoot common SQL Server issues.

# Technologies Used
- Microsoft SQL Server
- T-SQL
- SQL Server Management Studio (SSMS)

# Project Modules
1. Database Health Monitoring
2. Backup Monitoring
3. Performance Monitoring
4. Database Troubleshooting

# Project Purpose
This project demonstrates practical SQL Server skills and provides useful scripts for everyday database support activities.
